# Software Installation

Complete each step below before continuing to the NoRugs installation.

---

# Step 1 - Install Git

Git is used to download the NoRugs project from GitHub.

### Windows

1. Open your web browser.
2. Go to https://git-scm.com/downloads
3. Click **Download for Windows**.
4. Once the download finishes, open the installer.
5. If Windows asks if you want to allow the app to make changes, click **Yes**.
6. Continue clicking **Next** until you reach the **Install** button.
7. Click **Install**.
8. When installation is complete, click **Finish**.

### macOS

1. Open your web browser.
2. Go to https://git-scm.com/downloads
3. Click **Download for macOS**.
4. Download and install the latest version of Git.
5. Follow the installation prompts until complete.

---

# Step 2 - Install Visual Studio Code

Visual Studio Code is used to edit and run the NoRugs project.

### Windows

1. Open your web browser.
2. Go to https://code.visualstudio.com
3. Click the blue **Download for Windows** button.
4. Open the downloaded installer.
5. Click **Next**.
6. Accept the license agreement.
7. Click **Next** until you reach **Select Additional Tasks**.
8. Check the following boxes:
   - Add "Open with Code" action to Windows Explorer
   - Register Code as an editor for supported file types
   - Add to PATH (recommended)
9. Click **Next**.
10. Click **Install**.
11. Click **Finish**.

### macOS

1. Open your web browser.
2. Go to https://code.visualstudio.com
3. Click **Download for Mac**.
4. Open the downloaded ZIP file.
5. Drag **Visual Studio Code** into the **Applications** folder.
6. Open **Applications**.
7. Double-click **Visual Studio Code**.

---

# Step 3 - Install Node.js

Node.js is required to run the application.

### Windows

1. Open your web browser.
2. Go to https://nodejs.org
3. Click the **LTS** download button.
4. Open the downloaded installer.
5. Click **Next**.
6. Accept the license agreement.
7. Continue clicking **Next** until you reach **Install**.
8. Click **Install**.
9. Click **Finish**.

### macOS

1. Open your web browser.
2. Go to https://nodejs.org
3. Click the **LTS** download button.
4. Open the downloaded installer.
5. Follow the installation prompts.
6. Click **Finish**.

---

# Step 4 - Install PostgreSQL

PostgreSQL stores the NoRugs database.

### Windows

1. Open your web browser.
2. Go to https://www.postgresql.org/download/windows/
3. Click **Download the installer**.
4. On the EnterpriseDB website, click **Download** next to the latest PostgreSQL version.
5. Run the downloaded installer.
6. Click **Next**.
7. Leave all default components selected.
8. Click **Next**.
9. Create a password for the **postgres** user.
10. Write this password down. You will need it later.
11. Leave the port as **5432**.
12. Continue clicking **Next**.
13. Click **Install**.
14. Click **Finish**.

### macOS

1. Open your web browser.
2. Go to https://www.postgresql.org/download/macosx/
3. Click **Download the installer**.
4. Download the latest PostgreSQL installer.
5. Open the installer.
6. Follow the installation prompts.
7. Create a password for the **postgres** user.
8. Leave the port as **5432**.
9. Finish the installation.

---

Restart your computer before continuing.
